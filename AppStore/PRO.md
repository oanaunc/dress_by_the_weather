# Dress Pro — permanent upgrade

The owner chose a **US $19.99 one-time, non-consumable purchase**, with no subscription. The paywall displays Apple's localized product price and disables purchasing if the product cannot be loaded.

Product ID: `com.oanarinaldi.dressbytheweather.pro.lifetime`.

## Included features

- Seven-day outfit planner: save an occasion and photo variation for each available forecast day, per city. Today's saved occasion can be applied from the Today screen.
- Personal wardrobe: add and edit pieces, optional on-device photos, temperature comfort ranges, occasions, availability/laundry state and rain readiness. Recommendations match suitable owned pieces and identify missing categories.
- Travel capsules: use the destination's cold, warm, wet and windy periods; prefer suitable owned pieces already selected for reuse; keep daily combinations and a packing checklist. Basic packing lists remain free.
- Editorial library: 214 reviewed couple photographs with weather, temperature and occasion filters, saved inspiration, and eight original multi-look styling guides.

Global weather, current location, worldwide city search, hourly/daily forecasts, daily outfit advice, saved daily looks, basic trip packing and widgets remain free.

## Purchase behavior

StoreKit 2 verifies the signed lifetime entitlement. Cancellation grants nothing. Pending purchases wait for Apple approval. Purchases can be restored with the same Apple Account. Refund/revocation updates remove Pro access without deleting saved user data. Privacy settings allow deletion of Studio data independently of purchase status.

There is no receipt backend, advertising, analytics, credit-card collection or photo upload. Photos and wardrobe/planning records remain on the device. The `--pro-preview` shortcut is compiled only in Debug and requires explicit sample mode; Release builds have no purchase bypass.

`DressPro.storekit` is a local Apple test catalog. It does not create or replace the App Store Connect product record. The first purchase must be submitted with the first app version, including localized metadata, pricing and a review screenshot.
